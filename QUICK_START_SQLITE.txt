=====================================
SIPEDE SQLite Migration - Quick Start
=====================================

LANGKAH INSTALASI (PILIH SALAH SATU):

1. AUTOMATIC (RECOMMENDED):
   
   Double-click file ini:
   > INSTALL_SQLITE.bat
   
   Atau jalankan:
   > powershell -ExecutionPolicy Bypass -File Install-SQLite.ps1

2. MANUAL:
   
   cd sipede-scraper/backend
   npm install
   npm run migrate

=====================================

SETELAH INSTALL:

Jalankan aplikasi seperti biasa:
> Start-WebScraper.bat

=====================================

VERIFY:

Cek apakah file ini ada:
sipede-scraper/backend/data/sipede_data.db

Jika ada = BERHASIL!
